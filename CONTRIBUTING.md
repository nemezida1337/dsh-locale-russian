# Как помочь переводу

Спасибо за интерес! Здесь три роли: читатель, который нашёл ошибку перевода, переводчик и мейнтейнер выпусков. Ниже — что делать в каждой.

## Нашли ошибку перевода

Откройте [issue по шаблону «Ошибка перевода»](https://github.com/nemezida1337/dsh-locale-russian/issues/new?template=translation-error.yml): укажите экран, текущий текст и предлагаемый вариант. Если строка **новая** и ещё не переведена — это ожидаемо: недостающие строки показываются по-английски до следующего выпуска.

## Предлагаете правку переводов (pull request)

1. Форкните репозиторий и создайте ветку.
2. Правьте **`dictionary/overrides.json`** — это слой редакторских решений поверх переводов. Правки в `translations/*.json` допустимы для новых строк, но при следующем `npm run refresh` батчи пересобираются, а слой overrides сохраняется.
3. Сверьтесь с [GLOSSARY.md](GLOSSARY.md) (термины) и [STYLE.md](STYLE.md) (правила, склонения).
4. Прогоните проверки: `npm test`. В PR должен быть зелёный прогон — линтер, сборка, проверка бандла, тесты провайдера, установки движка, инструмента перевода, дашборда, фида и шаблона.
5. Опишите в PR, что и почему изменили.

### Правила перевода

- Термины — строго по глоссарию: `session` → «сессия», `conversation` → «диалог», `bundle` → «набор», `worktree` → «рабочее дерево», `change request` → «запрос изменения».
- Склонения: значение может содержать до трёх форм через `|` — одна|несколько|много. Для двух форм (ключи `.other`) действует порядок «несколько|много».
- Плейсхолдеры `{name}`, `{count}` не переводятся и не теряются — это проверяет линтер.
- Не переводим: имена пакетов, команд, моделей, провайдеров и брендов; данные хоста (описания навыков из `SKILL.md`).
- Многоточие — «…», кавычки — «ёлочки», ё пишется там, где она есть.

## Ведёте выпуски (мейнтейнер)

После обновления DeepSeek Harness:

```sh
npm run refresh          # снять дельту с приложения, CLI и репозитория
npm run translate -- --provider openai --base-url … --model …   # черновик перевода (опционально)
npm run mark-translated  # запомнить, по какому английскому сделан перевод
npm test                 # все проверки
npm run sweep -- --url … # обход интерфейса (опционально, нужен запущенный dsh web)
npm version patch && git push --follow-tags
```

Детектор в CI сам проверит свежие `latest`, `next` и `alpha`, а также сборку приложения из публичного фида, и откроет issue при дельте.

## Добавляете новый язык

В репозитории есть шаблон и генератор:

```sh
node tools/scaffold-locale.mjs --id de --label Deutsch --package dsh-locale-german
```

Сгенерированный пакет — рабочий каркас: объявляет язык, устойчив к занятым слотам каталога, умеет склонения через `Intl.PluralRules` и проходит собственный самотест (`node test.mjs`). Заполните `DICTIONARIES` и `PLUGIN_TEXT` в `lib/client.js` переводами и выпускайте.
