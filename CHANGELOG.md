## 0.5.0

**Прогрев движка распознавания**

- Движок запускается в фоне после старта приложения, если провайдер `gigaam-local` выбран по умолчанию и модель подготовлена: первая диктовка больше не ждёт загрузки модели. Задержка — 5 секунд, чтобы интерфейс успел загрузиться; поведение отключается настройкой `prewarm: false`, задержка — `prewarmDelayMs`.
- Смена провайдера в настройках подхватывается через поток состояния сервиса: выбрав русский распознаватель, движок прогревается сам.
- Прогрев не скачивает ничего сам: без движка или модели он молча пропускается, а ошибки пишутся в лог и не мешают работе.

**Вычитка перевода**

- `npm run review` — инструмент вычитки: модель-рецензент (те же провайдеры `mock`/`command`/`openai`) проверяет пары «английский → русский» на искажение смысла, нарушение глоссария, потерю плейсхолдеров и длину, и пишет отчёт `reports/review.md`. `--fail-on-issues` возвращает ошибку при замечаниях.
- Провайдеры вынесены в общий модуль `tools/lib/translate-providers.mjs`; протокол провайдера `command` теперь `{system, payload}` → JSON-массив.

**Правки после вычитки**

- Прочитаны все 1006 пар дельты 0.2.2; исправлено 10 формулировок: «Необработанный результат» вместо «Исходный», «затраченное время» вместо «прошедшего», «Показать все шаги ({total})» вместо неверного согласования при count=1, «Отменяется…», «Применение изменений к {name}», «Предлагается», «кэш» и «рецензии» в описаниях плагинов, заглавная буква в цитате примера.

**Проверки**

- `npm test` включает тест прогрева (5 сценариев: выбранный провайдер, отключённый прогрев, другой провайдер, нет модели, смена провайдера) и тест вычитки (13 проверок).

## 0.4.0

**Голосовой ввод в одну кнопку**

- Кнопка «Скачать и подготовить» ставит и движок, и модель: платформенная сборка `gigastt` (macOS arm64, Linux x64/arm64, Windows x64) скачивается с проверкой контрольной суммы релиза, распаковывается и проверяется запуском, затем качается модель. Прогресс обоих шагов виден в карточке.
- Неподдерживаемая платформа объясняет, что скачать вручную и где указать `binaryPath`; `install.sh` и `npx dsh-locale-russian-install` остаются альтернативой.

**Черновой перевод дельты**

- `npm run translate` читает батчи из `npm run refresh` и переводит их провайдером: `mock` (тесты), `command` (внешняя программа) или `openai` (любой OpenAI-совместимый endpoint). Проверяет плейсхолдеры, пустоту и длину, пишет `translations/` со свободными id; результат — черновик для вычитки.

**Дашборд покрытия**

- `market/index.html` на GitHub Pages: версия, строки, namespace, описания, совместимость, разбивка по источникам и ссылки. Собирается при каждом обновлении индекса.

**Проверка сборки приложения в CI**

- Job `app-drift` (macOS, ежедневно и вручную): скачивает сборку приложения из публичного фида обновлений, сверяет sha512, распаковывает `app.asar`, проверяет покрытие в изолированной копии репозитория и кэширует только `app.asar` (~200 МБ). При дельте открывает issue.

**Языковые паки для сообщества**

- `contrib/locale-template` и `tools/scaffold-locale.mjs`: генератор нового языкового пака (`--id de --label Deutsch --package dsh-locale-german`). Шаблон объявляет язык, устойчив к занятым слотам каталога, выбирает склонения через `Intl.PluralRules` и проходит собственный самотест.

**Участие**

- `CONTRIBUTING.md` для переводчиков и мейнтейнеров; шаблон issue «Ошибка перевода» с меткой `translation`; еженедельный workflow проверяет ответы в обсуждениях DeepSeek Harness и создаёт или обновляет issue.

**Проверки**

- `npm test` теперь включает восемь офлайн-наборов: линтер и импорты, бандл, хост-половина, установка движка (16), инструмент перевода (16), дашборд, разбор фида приложения, генератор паков, отчёт по обсуждениям.

- Детектор дельты на обновлённом приложении: 0 непереведённых строк и 0 описаний без перевода.

## 0.1.3

**Изменено**

- Из словаря убраны два ключа, которых нет ни в одной текущей сборке DSH: `chat/message.accountStopped` и `pluginManager/officialTitle`. Теперь словарь совпадает с инвентарём источников ключ в ключ.
- Генератор клиентского бандла вынесен в `tools/templates/client-bundle.js`: код бандла проверяется `node --check` и правится как обычный файл, а сам генератор сократился с 433 до 231 строки.
- Инструменты используют общий разбор аргументов `tools/lib/cli.mjs` (поддержаны обе формы: `--name value` и `--name=value`).
- Запуск headless Chrome берёт свободный порт автоматически (раньше фиксированный порт мог достаться чужому процессу, и CDP-команды возвращали `Not supported`); завершение процесса надёжное, временные профили не накапливаются.
- В `npm test` добавлена проверка согласованности импортов `node:fs` — она ловит класс ошибок, который иначе всплывает только при запуске конкретного инструмента.

**Исправлено**

- Обрезка подписей на Linux: названия карточек пресетов и бейдж основного пресета не помещались в контейнеры шириной 81–97 px. Формы сокращены («Стандарт», «Минимум», «Создание», «Основной»), решение закреплено в глоссарии.

**Добавлено**

- Описания платформенных пакетов: системные бинарники Linux (x64 и arm64), движки LibreOfficeKit для win32-x64, сборка OOXML-to-PDF для Linux, а также логгер и HMR Cordis.

**Проверки**

- Обход интерфейса выполняется на Ubuntu и Windows: шрифтовые метрики различаются, и Linux уже находил обрезки, которых нет на macOS.
- Детектор обновлений DSH проверяет обе платформы — платформенные пакеты устанавливаются только на своей ОС.
- Обход различает нашу копию и данные хоста: описания навыков из `SKILL.md` и имена пакетов не переводятся, поэтому их обрезка не считается провалом.
- Индекс маркета проверяется официальным валидатором DSH на каждом прогоне.

## 0.1.0 — первый выпуск

**Перевод**

- 3058 строк интерфейса в 65 namespace: панели, настройки, диалоги, карточки инструментов, подсказки, статусы, единицы измерения и форматы дат.
- 420 строк метаданных плагинов: описания и человекочитаемые названия пакетов для раздела «Встроенные плагины» (включая платформенные варианты для Linux и Windows).
- Единая терминология: глоссарий и правила стиля, проверяемые линтером (в том числе запрещённые варианты и склонения).

**Русские склонения**

- Формы выбираются по `Intl.PluralRules('ru')`: «1 файл», «2 файла», «5 файлов», «21 файл».
- Предформатированные числа («12.5K») распознаются, поэтому согласование работает и с ними.
- Для английского и китайского интерфейсов поведение не меняется.

**Установка**

- Пакет одновременно является bundle и клиентским плагином: `dsh plugin --profile web add dsh-locale-russian` добавляет его в профиль целиком.
- Поддержана установка из git, tarball и локального пути; для маркета плагинов собирается индекс формата 1.

**Качество**

- Линтер: плейсхолдеры, терминология, склонения, пустые значения, длина.
- Проверка собранного бандла без браузера: регистрация языка, словарей, склонения, метаданные, неизменность других локалей.
- Обход интерфейса в headless-браузере: 8–11 экранов, поиск обрезанного текста.
- CI: проверки на каждый push, недельный детектор обновлений DSH и дымовой тест с настоящим сервером.
