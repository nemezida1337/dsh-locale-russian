# История изменений

## 0.1.2

**Исправлено**

- Собственные метаданные пакета (`locale/en.json`, `locale/ru.json`) показывали устаревшие числа: 3056 строк вместо 3058 и без количества строк описаний плагинов. Теперь в карточке плагина видны актуальные значения.

## 0.1.1

**Исправлено**

- Обрезка подписей на Linux: названия карточек пресетов и бейдж основного пресета не помещались в контейнеры шириной 81–97 px. Формы сокращены («Стандарт», «Минимум», «Создание», «Основной»), решение закреплено в глоссарии.
- Обрезка подписи «Встроенные плагины» в боковой панели настроек (143 px в контейнере 112 px) — раздел называется «Встроенные».

**Добавлено**

- Описания платформенных пакетов: системные бинарники Linux (x64 и arm64), движки LibreOfficeKit для win32-x64, сборка OOXML-to-PDF для Linux, а также логгер и HMR Cordis.
- 56 строк метаданных плагинов и 2 строки интерфейса, которые показывала сборка 0.2.1-rc.2, но которых не было в таблице.

**Проверки**

- Обход интерфейса выполняется на Ubuntu и Windows: шрифтовые метрики различаются, и Linux уже находил обрезки, которых нет на macOS.
- Детектор обновлений DSH проверяет обе платформы — платформенные пакеты устанавливаются только на своей ОС.
- Обход различает нашу копию и данные хоста: описания навыков из `SKILL.md` и имена пакетов не переводятся, поэтому их обрезка не считается провалом.
- Индекс маркета проверяется официальным валидатором DSH на каждом прогоне.

## 0.1.0 — первый выпуск

**Перевод**

- 3058 строк интерфейса в 65 namespace: панели, настройки, диалоги, карточки инструментов, подсказки, статусы, единицы измерения и форматы дат.
- 420 строк метаданных плагинов: описания и человекочитаемые названия пакетов для раздела «Встроенные плагины» (включая платформенные варианты для Linux и Windows).
- Единая терминология: глоссарий и правила стиля, проверяемые линтером (в том числе запрещённые варианты и склонения).

**Русские склонения**

- Формы выбираются по `Intl.PluralRules('ru')`: «1 файл», «2 файла», «5 файлов», «21 файл».
- Предформатированные числа («12.5K») распознаются, поэтому согласование работает и с ними.
- Для английского и китайского интерфейсов поведение не меняется.

**Установка**

- Пакет одновременно является bundle и клиентским плагином: `dsh plugin --profile web add dsh-locale-russian` добавляет его в профиль целиком.
- Поддержана установка из git, tarball и локального пути; для маркета плагинов собирается индекс формата 1.

**Качество**

- Линтер: плейсхолдеры, терминология, склонения, пустые значения, длина.
- Проверка собранного бандла без браузера: регистрация языка, словарей, склонения, метаданные, неизменность других локалей.
- Обход интерфейса в headless-браузере: 8–11 экранов, поиск обрезанного текста.
- CI: проверки на каждый push, недельный детектор обновлений DSH и дымовой тест с настоящим сервером.
