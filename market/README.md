# Индекс маркета плагинов

Этот каталог — готовый к публикации индекс маркета DSH (формат 1). Он описывает пакет `dsh-locale-russian` так, чтобы страница **Плагины → Discover** могла показать карточку и установить плагин, не обращаясь к npm за метаданными.

Файлы:

- `index.json` — сам индекс; собирается командой `node tools/build-market.mjs` из `package.json`, руками не правится.
- `icon.svg` — иконка для карточки; копия корневой `icon.svg`.

## Как опубликовать

1. Соберите индекс: `node tools/build-market.mjs`.
2. Выложите **содержимое этого каталога** на статический https-хостинг. Проще всего GitHub Pages: положите файлы в ветку `gh-pages` (или в каталог `/docs` ветки `main` и включите Pages для него).
3. Проверьте адрес: `https://nemezida1337.github.io/dsh-locale-russianssian/index.json` должен отдавать JSON, а `.../icon.svg` — иконку.
4. Сообщите пользователям адрес индекса. Они добавляют его на странице **Плагины → Discover** (или в конфигурации строки `plugin-market` профиля, поле `indexes`).

Индекс может перечислять и другие пакеты: массив `plugins` — обычный список, а `metadata.categories`, `metadata.labels` и `metadata.sortKeys` описывают фильтры и сортировки, которые увидят пользователи.

## Правила, которые проверяет DSH

- `format` — ровно `1`.
- `title` и другие локализованные поля — строка либо объект с обязательным ключом `en`; языковые ключи строчные (`en`, `ru`, `zh-cn`).
- `icon` — либо `data:`-URL (SVG/PNG/JPEG/WebP до 32 КиБ), либо ссылка, которая разрешается относительно адреса индекса: либо `https:`, либо тот же origin.
- У каждого плагина: `name` (валидное имя npm-пакета), непустой `versions`, у каждой версии — `version`, `publishTimestamp` (Unix-секунды), `source` и `engines.dsh`.
- `source.type: "npm"` означает установку из реестра; для установки из Git указывают `url`, `commit` и необязательный `path`, и тогда версия ставится по зафиксированному коммиту.
