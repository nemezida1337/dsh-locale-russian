# Индекс маркета плагинов

Этот каталог — готовый к публикации индекс маркета DSH (формат 1). Он описывает пакет `dsh-locale-russian` так, чтобы страница **Плагины → Обзор** (в английском интерфейсе — *Discover*) могла показать карточку и установить плагин, не обращаясь к npm за метаданными.

Файлы:

- `index.json` — сам индекс; собирается командой `node tools/build-market.mjs` из `package.json` и реестра npm (оттуда берётся время публикации версии), руками не правится.
- `icon.svg` — иконка для карточки; копия корневой `icon.svg`.

## Где он опубликован

Индекс выкладывается автоматически workflow-ом `.github/workflows/pages.yml` на GitHub Pages:

```
https://nemezida1337.github.io/dsh-locale-russian/index.json
```

Пользователи добавляют этот адрес на странице **Плагины → Обзор**, после чего карточка появляется в списке. Проверить, что всё живо, можно так:

```sh
curl -s https://nemezida1337.github.io/dsh-locale-russian/index.json | head -20
curl -sI https://nemezida1337.github.io/dsh-locale-russian/icon.svg | head -1
```

## Как опубликовать свой индекс

1. Соберите индекс: `node tools/build-market.mjs`.
2. Выложите **содержимое этого каталога** на статический https-хостинг: GitHub Pages (workflow уже настроен), любой другой хостинг или даже ветку `gh-pages`.
3. Проверьте адрес: `index.json` должен отдавать JSON, а `icon.svg` — иконку.
4. Сообщите пользователям адрес индекса.

Индекс может перечислять и другие пакеты: массив `plugins` — обычный список, а `metadata.categories`, `metadata.labels` и `metadata.sortKeys` описывают фильтры и сортировки, которые увидят пользователи.

## Правила, которые проверяет DSH

- `format` — ровно `1`.
- `title` и другие локализованные поля — строка либо объект с обязательным ключом `en`; языковые ключи строчные (`en`, `ru`, `zh-cn`).
- `icon` — либо `data:`-URL (SVG/PNG/JPEG/WebP до 32 КиБ), либо ссылка, которая разрешается относительно адреса индекса: либо `https:`, либо тот же origin.
- У каждого плагина: `name` (валидное имя npm-пакета), непустой `versions`, у каждой версии — `version`, `publishTimestamp` (Unix-секунды), `source` и `engines.dsh`.
- `source.type: "npm"` означает установку из реестра; для установки из Git указывают `url`, `commit` и необязательный `path`, и тогда версия ставится по зафиксированному коммиту.

Проверить индекс перед публикацией можно официальным валидатором DSH, не выходя из репозитория:

```sh
npm run validate-market
```

Полное описание формата — в библиотеке-валидаторе `@deepseek-ai/dsh-plugin-market-index` из состава DeepSeek Harness и в разделе [«Индекс маркета»](../README.md#индекс-маркета) основного README.
