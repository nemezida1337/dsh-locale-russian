# Глоссарий DSH → русский

Единый источник терминологии для пакета `dsh-locale-ru`. Перевод **обязан** следовать таблице; линтер проверяет запрещённые варианты.

Правила чтения:

- **Термин** — английский оригинал, **Перевод** — как писать в интерфейсе.
- **Не переводить как** — запрещённые варианты (проверяются линтером).
- Регистр подсказывает форма: строчная — внутри фразы, с заглавной — самостоятельная подпись кнопки/заголовка.

## Чего не делаем

- Не переводим имена собственные, идентификаторы, названия плагинов, инструментов, команд, флагов, файлов и путей.
- Не переводим аббревиатуры из первой таблицы.
- Не добавляем вежливое «Пожалуйста» там, где его нет в оригинале.
- Не превращаем короткие подписи в предложения.

## Метаданные плагинов

Описания и названия пакетов-плагинов приходят из их `package.json` как `LocalizedText` и попадают в интерфейс через `LocaleRuntime.resolveText`. Пакет переводит их отдельной таблицей (`dictionary/plugin-meta.json`, ключ — английский текст), поэтому:

| Термин | Перевод | Заметки |
|---|---|---|
| capability seam | шов возможностей | Архитектурный термин проекта; «<x> seam (ctx.y)» → «шов <x> (ctx.y)» |
| read-only (в прозе) | только для чтения | В названии режима разрешений остаётся «Только чтение» |
| composer | поле ввода | Не «композер» |
| custom ( markets ) | пользовательские | Исключение из «свой» — только для «custom plugin markets» |
| spill storage | хранилище переполнения | Глагол spill — «сбрасывается во временный файл» |
| occupant | заполнитель | Занимающий слот плагин |
| facet | фасет | |

### Короткие подписи в тесных контейнерах

Названия карточек пресетов и бейдж «основной пресет» делят строку с бейджем и идентификатором, поэтому на Linux (шрифтовые метрики шире) длинные формы обрезаются. Закреплены короткие варианты:

| Английский | Русский | Почему не длиннее |
|---|---|---|
| Standard mode | Стандарт | контейнер ~81 px |
| Minimal mode | Минимум | делит строку с идентификатором `minimal` |
| Creator mode | Создание | делит строку с идентификатором `cordis` |
| PTC mode | Режим PTC | помещается |
| New task default | Основной | бейдж отнимает место у названия |
