# Замены: как они работают

Замены — это пары «как услышали → как надо». В отличие от слов словаря (которые подсказывают движку написание), замены применяются к тексту **после** распознавания и срабатывают всегда, даже если движок уверенно написал неверно.

Пример: движок слышит «гитхап» и пишет «гитхап»; в заменах есть пара `гитхап → GitHub` — в поле ввода появляется `GitHub`.

## Как создать замену

1. **Из поповера**: выделите неверное слово в поле ввода → в поповере выберите кандидата (`GitHub`) — слово заменится, а пара запомнится.
2. **Авто-обучение**: продиктуйте, исправьте слово в тексте — пара запомнится сама (неуверенные пары спросят подтверждение).
3. **Импорт JSON**:
   ```sh
   npx dsh-locale-russian-install --hotwords-import pairs.json
   ```
   ```json
   { "replacements": { "гитхап": "GitHub", "опена": "OpenAI" } }
   ```
4. **Вручную** — `~/.dsh/speech-ru/replacements.json` (приложение читает файл на лету).

## Как замена срабатывает

- **Без учёта регистра**: «Гитхап» и «гитхап» — одна пара.
- **Русские падежи**: пара `гитхаб → GitHub` сработает и для «на гитхабе», «без гитхаба». Английские формы не склоняются, «гитхабер» не тронется.
- **От длинных к коротким**: если есть пары `гит` и `гитхаб`, сначала применяется длинная — «гитхаб» не превратится в «GITхаб».
- **Видимость**: заменённое слово подсвечивается синим пунктиром; клик — поповер с вариантами и «Вернуть: …».
- **Ручной ввод не трогается**: замены применяются только к распознанному тексту.

## Как управлять

- **Окно словаря** (Cmd+Shift+D) → секция «Замены (N)»: список пар, удаление кнопкой **×**.
- **CLI**: `--hotwords-export pairs.json` (выгрузить), `--hotwords-import pairs.json` (загрузить), `--hotwords-list` (слова, не замены).
- Пары можно передавать коллеге вместе со словарём через экспорт/импорт.

## Опасные пары

- **Слишком широкие**: «слаке → Slack» может мешать, если вы говорите «слайде». Если замена сработала не туда — удалите пару.
- **Обрывки**: не добавляйте пары для частей термина — только целые слова/фразы.
- **Смысловые правки**: «сделал → сделала» — это грамматика, её учить не нужно; авто-обучение такие пары пропускает.
- **Проверяйте после обучения**: первое время смотрите на синюю подсветку — она показывает, что именно заменено.

## Если замена не срабатывает

1. Проверьте пару в окне словаря (Cmd+Shift+D).
2. Убедитесь, что слово действительно распознано (а не набрано руками).
3. Посмотрите `~/.dsh/speech-ru/transcripts.json` (если включён `debugTranscripts`) — там видно, что услышали GigaAM и Whisper.
4. Если движок слышит иначе — добавьте ещё одну пару с реально услышанной формой или исправьте слово в поле и дайте авто-обучению запомнить.
