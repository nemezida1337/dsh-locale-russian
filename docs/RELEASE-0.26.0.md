# Релиз 0.26.0 — уведомления об обновлениях

**Дата:** 2026-11-06 · **Тесты:** 718 · **Покрытие DSH 0.2.2-rc.1:** полное

## Что нового

- **Тихий индикатор обновлений.** Плагин проверяет фид при старте и раз в 6 часов. В левом нижнем углу появляется небольшая капсула «Обновление 0.26.0»/«Критично: обновление…» — без модалок и без перекрытия работы.
- **Разворот с изменениями.** Версия «установлено → доступно», пункты «Новое / Исправлено / Безопасность», предупреждение о перезапуске, ссылка на CHANGELOG.
- **Действия:** «Обновить» (через штатный plugin-manager DSH с его откатом; если API недоступен — копируется команда установщика), «Позже» (24 часа), «Пропустить версию» (до следующей), «Все изменения».
- **Критичные версии** помечаются в фиде `market/updates.json`; шумные обновления можно отложить.
- Фид собирается из CHANGELOG командой `npm run updates:build`, публикуется на сайте как `/updates.json`; `npm test` проверяет его актуальность.

## Накопленные исправления после 0.25.1

- Recovery: ложная панель после длинной диктовки, очередь нескольких диктовок, маппинг транскриптов, защита от дублей и вставки в чужой чат.
- Слияние: `sentences` не теряет и не дублирует фразы, `auto` не перемешивает их при разной разбивке.
- Настройки/словарь: ошибка хоста с повтором, Escape отменяет открытие, generation-guard от гонок.
- Безопасность: SSRF IPv6-формы (IPv4-mapped, NAT64, 6to4, Teredo, не-глобальные диапазоны).
- Нативный ru: описания сторонних плагинов снова переводятся, нативные словари не перезаписываются.
- Вставка: подсветка и авто-обучение после ручной/поздней вставки; каретка реагирует только на текст поля.
- Host: `/transcriptions`, история подхватывается при старте, безопасный обработчик, кэш рабочего порта.

## Установка

```sh
npx dsh-locale-russian-install --desktop
```

Локальные dev-сборки (`file:`/`link:`) из реестра не обновляются — для автообновления нужна установка из npm.

## Чек-лист выпуска

1. `npm test` — 718 проверок.
2. `node tools/check-app.mjs` — покрытие полное.
3. `npm run updates:build` — фид актуален.
4. Тег `v0.26.0` → npm publish; пуш `main` → сайт и market.
5. GitHub Release и проверка на живом приложении: чип обновления, разворот, «Позже»/«Пропустить».
