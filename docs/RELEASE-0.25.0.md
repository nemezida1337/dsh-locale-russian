# Релиз 0.25.0 — быстрая диктовка и динамические словари

**Дата:** 2026-11-06 · **Тесты:** 610 · **Покрытие DSH 0.2.2-rc.1:** полное

## Что нового

- **Режим `auto` по умолчанию.** GigaAM отвечает за **0,15–0,22 с** на обычном русском; Whisper подключается только на английских терминах, транслитерациях и при низкой уверенности. Тёплый `whisper-server` (~0,7 с вместо ~1,1 с), предзагрузка обоих движков.
- **Длинные диктовки без потерь.** Аудио режется по тихим точкам, prompt Whisper — «Термины: …», предложения выравниваются по смыслу: пунктуация восстановлена, абзацы не теряются.
- **Словарь-продукт.** Динамические профили (работа / проект / личное) с автопереключением, лимит 400 слов на словарь, статистика пользы `×N`, retention-чистка с «Вернуть», импорт по URL, активный профиль прямо в окне.
- **Совместимость с DSH 0.2.2.** Приложение везёт нативный русский язык: плагин определяет это и больше не переписывает словари — стоковые плагины загружаются нормально. На старых DSH перевод работает как раньше.
- **Восстановление диктовки.** Если транскрипт не попал в поле ввода, появляется панель «Вставить / Скопировать»; текст живёт 30 минут.
- **Надёжность и безопасность.** CSRF-заголовок, валидация профилей, SSRF-защита импорта, защита словаря от инъекции маркеров, гонки закрытия окон.

## Установка

```sh
npx dsh-locale-russian-install --desktop
```

Перезапустите приложение. Для веб-профиля: `dsh plugin --profile web add dsh-locale-russian`. Индекс для установки без терминала: `https://nemezida1337.github.io/dsh-locale-russian/index.json`.
