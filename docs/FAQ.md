# Частые вопросы

## Установка

**Как поставить пакет в приложение DeepSeek Harness?**

Одной командой — она сама найдёт профиль приложения, сделает резервную копию и поставит пакет:

```sh
npx dsh-locale-russian-install --desktop
```

Затем перезапустите приложение и выберите язык в «Настройки → Общие → Язык». Посмотреть изменения без записи — `--dry-run`, откатить — `--revert`.

Без терминала: включите «Пользовательские рынки плагинов» на странице «Плагины», откройте «Обзор» → «Источники индексов», добавьте адрес `https://nemezida1337.github.io/dsh-locale-russian/index.json` и установите пакет из «Обзора».

**Как поставить в web-профиль (`dsh web`)?**

```sh
dsh plugin --profile web add dsh-locale-russian
```

**Почему в приложении пакет не ставится через `dsh plugin`?**

Профиль `desktop` принадлежит приложению, и CLI отказывается им управлять — это защита от порчи настроек. Поэтому для приложения есть `--desktop` (или «Обзор» в интерфейсе).

**Интерфейс остался английским. Что проверить?**

1. «Настройки → Общие → Язык» — выбран «Русский»;
2. пакет есть в списке установленных;
3. приложение перезапущено после установки.

Если язык выбран, но часть строк английская — так и должно быть для новых строк: они показываются по-английски до следующего выпуска.

## Голосовой ввод

**Почему микрофона нет или он не работает?**

Голосовой ввод — это штатный плагин DSH, в поставке он выключен. Включите «Голосовой ввод» на странице «Плагины», затем откройте его карточку и нажмите «Скачать и подготовить»: скачаются движок и модель (~313 МБ), прогресс виден в карточке. После этого перезапустите приложение.

**Сколько это занимает места и памяти?**

Около 313 МБ на диске (движок 42 МБ + модель 271 МБ) и примерно 330 МБ оперативной памяти во время работы. Движок прогревается в фоне, когда провайдер выбран по умолчанию.

**Нужны ли ключи API или интернет?**

Нет. Распознавание идёт на вашем компьютере, аудио никуда не отправляется, ключи не нужны. Интернет требуется только для скачивания движка и модели.

**На каких платформах работает голосовой ввод?**

Движок есть для macOS arm64, Linux x64/arm64 и Windows x64. На других платформах его можно поставить вручную из [релиза gigastt](https://github.com/ekhodzitsky/gigastt/releases) и указать `binaryPath`.

**Как добавить свои слова в распознавание?**

Допишите фразы в `~/.dsh/speech-ru/hotwords.txt`, по одной на строку. Изменения подхватываются со следующей диктовки.

## Обновление и удаление

**Как обновиться?**

- приложение: менеджер плагинов сам показывает «Доступно обновление»; либо повторите `npx dsh-locale-russian-install --desktop`;
- web-профиль: `dsh plugin --profile web add dsh-locale-russian@latest`.

Если pnpm сразу после выпуска ставит предыдущую версию — так работает его защита от слишком свежих пакетов: укажите версию явно или повторите позже.

**Как удалить?**

- приложение: `npx dsh-locale-russian-install --desktop --revert` (или удалите пакет на странице «Плагины»);
- web-профиль: `dsh plugin --profile web remove dsh-locale-russian`.

Движок и модель остаются в `~/.dsh/bin` и `~/.gigastt` — их можно удалить вручную.

## Перевод

**Где задать вопрос или предложить идею?**

В [обсуждениях репозитория](https://github.com/nemezida1337/dsh-locale-russian/discussions): категория «Вопросы» для проблем с установкой и голосовым вводом, «Идеи» для предложений. Ошибки перевода удобнее оформлять issue по шаблону.

**Как сообщить об ошибке перевода?**

[Issue по шаблону «Ошибка перевода»](https://github.com/nemezida1337/dsh-locale-russian/issues/new?template=translation-error.yml): укажите экран, текущий текст и предлагаемый вариант. Правки принимаются и пул-реквестами — см. [CONTRIBUTING](../CONTRIBUTING.md).

**Почему оболочка приложения (меню, диалоги) по-английски?**

Оболочка Electron не использует каталог локалей клиента, поэтому внешний плагин её не переводит. Предложение отправлено в upstream: [discussions/10148](https://github.com/deepseek-ai/deepseek-harness/discussions/10148).

**Почему описания навыков в меню `/` по-английски?**

Хост отдаёт их обычными строками, без локализуемых метаданных. Предложение: [discussions/11533](https://github.com/deepseek-ai/deepseek-harness/discussions/11533).

**Есть ли другие языки?**

В репозитории есть шаблон и генератор языковых паков: `node tools/scaffold-locale.mjs --id de --label Deutsch --package dsh-locale-german`. Схема проверена на русском пакете.

**Собираете статистику?**

Нет. Пакет не отправляет телеметрию: единственный сетевой обмен — npm при установке и загрузка движка с моделью по вашему действию.
