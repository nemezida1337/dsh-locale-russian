# Релиз 0.25.1 — хотфикс

**Дата:** 2026-11-06 · **Тесты:** 619 · **Покрытие DSH 0.2.2-rc.1:** полное

## Что исправлено

- **Настройки диктовки на DSH 0.2.2.** Приложение грузит интерфейс со схемы `dsh-app://app`, а локальный сервер словаря доверял только `127.0.0.1`/`localhost`/`Origin: null`. Все запросы настроек получали `cross-site`: «Динамические словари» висели на загрузке, «Проверить диктовку» и «Словарь» выдавали ошибку. Теперь origin `dsh-app://` (и `file://`) доверяется только при Electron/DeepSeek Harness UA, для preflight добавлен `Access-Control-Allow-Private-Network`.
- **Перестановка фраз в диктовке.** При разной разбивке на предложения Whisper дописывал непарные фразы в конец, даже если они уже были сказаны. Теперь опорный порядок всегда GigaAM, хвост Whisper добавляется только при фонетической новизне.

## Установка

```sh
npx dsh-locale-russian-install --desktop
```

После установки перезапустите приложение: оба исправления находятся в host-части плагина.

## Чек-лист выпуска

1. `npm test` — 619 проверок.
2. `node tools/check-app.mjs` — покрытие полное.
3. Коммит, тег `v0.25.1`, пуш тега → npm publish.
4. Пуш `main` → сайт и market-индекс.
5. GitHub Release с этими заметками.
6. Проверка на живом приложении: настройки открываются, длинная смешанная диктовка без дублей в хвосте.
