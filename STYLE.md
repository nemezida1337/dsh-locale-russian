# Правила стиля русской локализации

Правила для строк интерфейса DeepSeek Harness. Дополняют [GLOSSARY.md](GLOSSARY.md); при конфликте выигрывает глоссарий.

## Голос и регистр

- Пишем как русскоязычный технический автор, а не как переводчик: смысл, а не порядок слов.
- Регистр оригинала сохраняем: короткая подпись остаётся короткой, официальная фраза — официальной.
- Обращение к пользователю — на «вы» со строчной буквы: `вы`, `ваш`. В императивах — инфинитив или повелительное наклонение, как в оригинале: `Сохранить`, `Отмена`, `Повторить`.
- UI-подписи — без точки в конце. Подсказки и описания — с точкой, если это полное предложение.
- Не добавляем вежливость, которой нет в оригинале (никаких «Пожалуйста» и «Попробуйте ещё раз» сверх исходного текста).

## Типографика

- Кавычки — «ёлочки»: `«Название»`. Внутри — „лапки“.
- Тире — длинное (`—`) с пробелами; дефис только внутри слов.
- Многоточие — один символ `…`, без пробела перед ним: `Загрузка…`.
- Двоеточие в подписях и статусах — как в оригинале: `Файлов: 3`.
- Перед `:` `;` `!` `?` пробел не ставится; после — ставится.
- Сокращения: `т. е.`, `напр.` — только там, где экономия действительно нужна; иначе полные слова.
- Числа и латиница внутри русского текста пробелами не отделяются: `3 файла`, `MCP-сервер`.
- Сокращение «ё» не делаем: пишем `тёмная`, `включён`, `объём`.

## Длина и раскладка

- Строка не должна быть длиннее оригинала более чем в 1,5 раза. Для кнопок, вкладок и пунктов меню — стремимся к длине оригинала.
- Не переносим смысл в скобки-уточнения, если можно сказать короче.
- Если английская строка — одно слово, русская тоже должна быть одним словом, когда это возможно.

## Плейсхолдеры и разметка

- Плейсхолдеры `{name}`, `{n}`, `{count}` сохраняются дословно, в тех же фигурных скобках, ровно по одному разу на каждое вхождение оригинала.
- Порядок плейсхолдеров можно менять под русский порядок слов: `{count} файлов из {total}`.
- Markdown-разметка (`**жирный**`, `` `код` ``), ссылки, HTML-теги и переводы строк сохраняются.
- Названия команд, клавиш, путей, идентификаторов и кодовых токенов — без перевода, в исходном виде: `compact`, `Ctrl+C`, `.dsh`, `pluginInventory`.
- Горячие клавиши пишем через `+` без пробелов: `Ctrl+Shift+P`.

## Множественные числа

Русский требует трёх форм, английский — двух, поэтому у ключей с числом есть соглашение:

- Значение может содержать разделитель `|` и до трёх форм: `одна форма` для всех чисел, `мало|много` для двух форм, `один|мало|много` для трёх.
- Для парных ключей `.one` / `.other` форма для чисел 1, 21, 31… берётся из ключа `.one`, поэтому в `.other` достаточно двух форм: `мало|много`.
- Форма выбирается по `Intl.PluralRules('ru')`: категория `one` → форма «один», `few` → «мало», `many` и `other` → «много».
- Примеры: `файл|файла|файлов`; `сессия|сессии|сессий`; `{n} файл|{n} файла|{n} файлов`.
- Согласование по роду и падежу — обязанность переводчика: `1 сессия`, `2 сессии`, `5 сессий`.
- Символ `|` не используется ни в каком другом значении; в обычной строке его быть не должно.

## Чего избегаем

- Кальки: `выполнить клик` → `нажать`; `иметь возможность` → `можно`; `является` → `—` или перестроить фразу.
- Канцелярита: `осуществляется загрузка` → `загружается`.
- Нагромождения отглагольных существительных: `выполнение сохранения файла` → `сохранение файла`.
- Смешения синонимов в одном экране: выбрав «рабочая область», не пишем рядом «рабочее пространство».
- Английских слов там, где есть устоявшийся русский термин (см. глоссарий).
- Заглавных букв в середине подписи: `Сохранить файл`, а не `Сохранить Файл`.
