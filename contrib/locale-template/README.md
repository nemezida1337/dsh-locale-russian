# __PACKAGE_NAME__

Языковой пакет (`__LANG_ID__`, «__LANG_LABEL__») для web-интерфейса [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). Создан из шаблона `dsh-locale-russian`.

## Что внутри

- `lib/client.js` — браузерная половина: объявляет язык, регистрирует словари и выбирает формы склонений через `Intl.PluralRules`.
- `lib/index.js` — хост-половина: пустая заглушка, нужна только для строки бандла.
- `cordis.patch.yml` — строка патча, которая подключает пакет.
- `locale/*.json` — собственные метаданные пакета для карточки плагина.
- `test.mjs` — самотест: язык, регистрация, склонения.

## Заполнить перевод

1. Соберите строки из установленного DSH: в репозитории `dsh-locale-russian` есть пайплайн (`npm run refresh`) и инструмент чернового перевода (`npm run translate`).
2. Перенесите переводы в `lib/client.js`:
   - `DICTIONARIES` — объект `namespace → key → строка`; для склонений используйте до трёх форм через `|` (одна|несколько|много), механизм выберет форму по `Intl.PluralRules`.
   - `PLUGIN_TEXT` — английские описания плагинов → перевод (подстановка идёт через `resolveText`).
3. Прогоните `node test.mjs` и проверьте пакет в приложении.

## Установка

```sh
dsh plugin --profile web add /абсолютный/путь/к/__PACKAGE_NAME__
```

Или соберите пакет в npm и ставьте по имени.

## Важные детали

- `id` клиентского бандла обязан совпадать с именем пакета — иначе DSH не загрузит модуль.
- Регистрация откладывается на следующий тик: каталог локали и соседние плагины успевают активироваться (на DSH 0.2.2 регистрация во время активации роняла `theme`).
- `addLanguage`/`register` устойчивы к уже занятым слотам: DSH 0.2.2 сам регистрирует часть языков и словарей.
- `engines.dsh` перечисляет проверенные сборки: pre-release версии требуют явного компаратора (`^0.2.2-alpha.2`).
